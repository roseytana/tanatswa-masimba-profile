## Accessibility

I used several accessibility practices when creating this website:

- Used semantic HTML5 elements such as `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`.
- Used a logical heading structure from `h1` to `h2` and `h3`.
- Added labels to all form fields.
- Used appropriate input types such as `text`, `email`, and `tel`.
- Added native HTML validation using the `required` attribute.
- Used clear and readable text.
- Used sufficient colour contrast between text and backgrounds.

### Accessibility Feedback and Fix

I checked the structure and form of the webpage to make sure it was easy to understand and navigate. I corrected the page structure and ensured that form fields had labels and appropriate validation.
